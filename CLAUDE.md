# CLAUDE.md — AI agent instructions (Nexus frontend)

Стек: Web frontend проекта Nexus (SvelteKit, TypeScript, Vite, Playwright).

## Поиск по коду
Поиск по компонентам и стилям делегировать субагенту `finder` (Haiku). При работе со стилями не читать лишние модули. Если пользователь указал конкретный файл через `@`, читать только его.

## Проверка кода
Использовать только проверку типов/линтер (через субагента `checker`): `npx tsc --noEmit` или линтинг. Не запускать полную production-сборку без запроса.

## Правило по тестам
Пиши необходимые тесты для логики/компонентов под CI/CD, но НИКОГДА не запускай test-раннеры (`npm test`, `vitest`, `jest`, `playwright` и т.д.) самостоятельно. Если тест упадет в CI, я сам передам лог ошибки.

## Логи и команды
При запуске `docker logs`, `git log` или SQL-запросов всегда ограничивай вывод (`--tail=30`, `-n 10`, `LIMIT 20`), чтобы не засорять контекст.

## Безопасность
Запрещено читать `.env*`, `node_modules/`, `.next/`, `dist/` и удалять любые данные/файлы проекта.

## Интерфейс
- Стрелки на концах полос прокрутки (вверх/вниз) на сайте не нужны и не должны появляться. Они скрыты в `src/routes/layout.css` (`::-webkit-scrollbar`, `::-webkit-scrollbar-button`). Новые скроллируемые блоки не должны их возвращать: не задавать свои стили полос, которые включают стрелки, и не использовать `overflow` без учёта подчёркиваний и теней, которые могут создать лишнюю полосу.
