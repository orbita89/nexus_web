# Особые коллекции: редактирование админом и режим шапки — задача бэкенду

Сейчас `PATCH /api/v1/social/collections/{id}` (название/описание) работает только для владельца — админ не может
поправить, например, «Дюна во всех видах» / «Книги и экранизации…» у чужой особой коллекции.
Стиль шапки жёстко привязан к обоям/теме: в режиме «Вся страница» нельзя сделать нейтральную шапку, и нельзя убрать шапку совсем.

## 1. Админ редактирует название и описание

`PATCH /api/v1/social/admin/collections/{id}` — для любой коллекции (минимум — особой).

```json
{ "title": "Дюна во всех видах", "description": "Книги и экранизации…" }
```

- Поля как в `UpdateCollection` (`title?`, `description?`), та же валидация (400 `code: "validation"`, `field`);
  не передано — не меняется. `is_public` здесь **не** меняется (поле игнорируется или 400).
- 403 — не админ, 404 — нет коллекции.
- Ответ — обновлённая Collection.

## 2. Новое поле Collection `header_mode`

| Поле          | Тип                               | Дефолт     |
| ------------- | --------------------------------- | ---------- |
| `header_mode` | `"styled" \| "plain" \| "none"`   | `"styled"` |

- `styled` — шапка в теме/с обоями (как сейчас);
- `plain` — нейтральная шапка без темы и обоев; остальной контент по-прежнему в теме (в т.ч. при `wallpaper_mode: "page"`);
- `none` — шапки (hero-блока) нет, название и описание — обычным заголовком над списком.

Возвращается в **каждом** ответе с Collection (списки, детальная, featured, admin), сбрасывается в `styled` при снятии «особости».
Задаётся через `PUT /api/v1/social/admin/collections/{id}/featured` `{ "header_mode": "plain" }` — не передано — не меняется, `null` — сброс в `styled`.
Валидация: значение ∉ {`styled`, `plain`, `none`} → 400 `code: "validation"`, `field: "header_mode"`.

## Фронт после реализации

- Перегенерировать типы из `documents/api/social.json`.
- `collections.ts`: `adminUpdateCollection(id, {title, description})`; `header_mode` в типах и `setFeatured`.
- Страница коллекции / `FeaturedAdminControls`: админу — редактирование названия и описания (через admin-эндпоинт для чужих, обычный PATCH для своих).
- `FeaturedStyleForm`: выбор «Шапка: в теме / нейтральная / без шапки»; `FeaturedCollectionView`/`CollectionBackdrop` — рендер по `header_mode`.
- Админка `/admin/collections`: колонка/поле режима шапки.
