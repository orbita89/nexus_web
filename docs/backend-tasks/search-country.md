# Фильтр по стране в поиске каталога

В карточке есть строка «Страна: Великобритания, США» — её хочется нажать и увидеть, что ещё
снято в этой стране. Год так и работает (`/films?year=2026` → `GET /search?year=2026`), а
по стране фильтра в API нет: у `GET /api/v1/catalog/search` параметры `q`, `sort`, `tag`,
`year`, `year_from`, `year_to`, `studio`, `studio_slug`, `publisher`, `museum`, `person`,
`role`, `award`, `award_year`, `awarded`, `limit`, `offset`, `kind`.

Страны при этом в данных есть: `metadata.countries` у фильмов и сериалов (в карточке мы их и
показываем), но в индексе Meilisearch они, судя по всему, не фильтруются.

## Что нужно

```
GET /api/v1/catalog/search?country=US&kind=movie
```

- Значение — код страны **ISO 3166-1 alpha-2** (`US`, `GB`, `FR`), как в `metadata.countries`.
  Названия («США») фронтенд показывает сам: у нас есть `countryName()` в `lib/catalog/labels.ts`.
- Параметр повторяемый или через запятую (`country=US,GB`) — «страна одна из перечисленных».
  Если проще сделать одиночным, этого на первое время достаточно: в карточке мы ведём по
  одной стране.
- Работает вместе с остальными фильтрами (`kind`, `year`, `tag`, `sort`), как они между собой.
- Неизвестный код — 400, чтобы мусор в адресе не выдавал пустую выдачу молча.

## Хорошо бы, но не обязательно

Подсказки стран, как у студий и тегов: `GET /api/v1/catalog/search/countries?kind=&limit=`
→ `[{ code, count }]` — тогда в фильтрах раздела появится выбор страны со счётчиками, а не
просто ссылка с карточки.

## Что фронтенд включит после

| Бэкенд                    | Фронтенд                                                    |
| ------------------------- | ----------------------------------------------------------- |
| `country` у `GET /search` | «Страна» в карточке становится ссылкой: `/films?country=US` |
| фасет `search/countries`  | выбор страны в фильтрах раздела, рядом с жанром и годом     |

После слияния: `pnpm api:types`, затем `pnpm verify`.
