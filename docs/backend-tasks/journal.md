# ТЗ бэкенду: журнал профиля

Вкладка «Журнал» на `/u/{username}/journal` показывает всё, что человек делал с произведениями, — одной записью на произведение. Пока эндпоинта нет, фронт (при 404) собирает журнал из `likes/given`, `ratings`, `reviews`, а владельцу — ещё из `users/me/marks` и `users/me/notes` (см. `src/lib/social/journal.fallback.ts`). Это упрощённый режим: первые 100 записей каждого источника.

## Эндпоинт

`GET /api/v1/social/users/{username}/journal`

Query:

| параметр | значения | по умолчанию |
|---|---|---|
| `filter` | `all` \| `likes` \| `reviews` \| `notes` \| `later` \| `ratings` | `all` |
| `kind` | `movie` \| `series` \| `book` \| `game` | все |
| `q` | поиск по названию произведения (на стороне бэкенда) | — |
| `limit` | 1–100 | 20 |
| `cursor` | непрозрачная строка из `next_cursor` | — |

Сортировка — по `last_activity_at DESC` (последнее действие над произведением), tie-break по `entity.id`.

## Ответ

```json
{
  "items": [
    {
      "entity": { "id": "uuid", "kind": "movie", "slug": "dune-2021", "title": "Дюна", "release_date": "2021-10-22", "cover_url": "..." },
      "actions": ["like", "rating", "review", "reaction", "note", "later", "done"],
      "last_activity_at": "2026-11-01T12:00:00Z",
      "rating": 8,
      "review": { "id": "uuid", "body": "...", "is_spoiler": false, "excerpt": "первые ~200 символов" },
      "note": { "body": "..." },
      "mark": "later"
    }
  ],
  "next_cursor": "opaque-or-null"
}
```

`rating`, `review`, `note`, `mark` — опциональны; `actions` перечисляет, что есть.

## Приватность

- `note` и `mark` (`later`, `done`), а также действия `note`/`later`/`done` в `actions` — **только если запрашивающий — владелец**. Гостю и другим пользователям не отдаются вовсе; решает сервер, фронт их не фильтрует.
- Фильтры `notes` и `later` у не-владельца — пустая выдача (или игнорируются, как `all` — на усмотрение бэкенда, фронт их гостю не предлагает).
- Публичные действия (лайки, оценки, рецензии, реакции) подчиняются тем же правилам, что остальная аналитика: 403 `stats_private`, если владелец не открыл статистику.
- Противоречие в доке («marks никому не видны» против перечня в `stats_private`) решено в пользу «отметки видит только владелец».

## Пагинация

Курсорная. `next_cursor = null` — конец. Смена фильтра/`kind`/`q` на фронте сбрасывает курсор.

## Опционально: обложка профиля

Поле `cover_url` (nullable) в `SocialProfile`. Пока его нет, фронт рисует градиентную полосу; блокировать работу не должно.
