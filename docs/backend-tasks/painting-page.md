# Страница картины: фрагменты, разбор и музей (задача бэкенду)

Карточка картины сейчас — то же, что карточка фильма: обложка, таблица фактов, рецензии. Для
холста этого мало. «Ночной дозор» — 363 × 437 см, на нём три десятка фигур, и вся ценность
страницы в том, чтобы показать его крупно и объяснить, на что смотреть: золотая девочка, рука
капитана, автопортрет Рембрандта в толпе.

Из `PaintingMetadata` сейчас есть `technique`, `museum`, `city`, `height_cm`, `width_cm` и
`trivia`. Ни фрагментов, ни разбора, ни нормального исходника для зума.

**Это больше, чем сезоны.** Сезоны были одной сущностью и тремя ручками; здесь четыре разных
куска, и они не равны по пользе. Порядок в документе — порядок внедрения, и остановиться можно
после любого пункта: каждый сам по себе уже делает страницу лучше. Если брать только один — берите
первый.

## 1. Фрагменты полотна — главное

Лента «Интересные детали полотна»: карточки с крупным планом куска картины и подписью
(«Скрытый автопортрет», «Аллегория гильдии»).

Ключевое решение: **фрагмент — это прямоугольник на исходнике, а не отдельно залитый файл.**

```json
{
	"id": "...",
	"title": "Скрытый автопортрет",
	"description": "В глубине толпы, между знаменем и шляпой, видно лицо самого Рембрандта.",
	"crop": { "x": 0.412, "y": 0.168, "width": 0.09, "height": 0.12 },
	"position": 3
}
```

- `crop` — доли от ширины и высоты исходника (0–1), а не пиксели: исходник могут перезалить в
  другом разрешении, и доли это переживут, а пиксели — нет.
- Почему не отдельные файлы: тогда фрагмент — это просто картинка рядом с картиной, и всё, что с
  ней можно сделать, — показать. С координатами фронт из той же ленты перелетает зумом к этому
  месту на самом холсте: нажал «Скрытый автопортрет» — картина увеличилась и показала лицо в
  толпе. Это то, ради чего раздел и нужен; сохранить его в отдельных JPEG нельзя.
- Порядок — `position`, как у титров: детали рассказывают по смыслу, а не слева направо.
- До 20 фрагментов на картину; `title` до 120 символов, `description` до 600.

Ручки:

| Метод                                               | Что делает                               |
| --------------------------------------------------- | ---------------------------------------- |
| `GET /api/v1/catalog/entities/{slug}/fragments`     | список, в порядке `position`             |
| `PUT /api/v1/catalog/admin/entities/{id}/fragments` | замена списка целиком, как `SetEpisodes` |

Отдавать их можно и прямо в `EntityDetail` у картин (их мало, и они нужны сразу) — тогда
отдельный `GET` нужен только админке. На ваше усмотрение, фронту удобнее в карточке.

## 2. Исходник, по которому можно зумить

Без этого пункт 1 бессмысленен: кропнуть 0.412 × 0.168 на превью шириной 600 px — это каша из
двенадцати пикселей.

Сейчас у картины только `cover_url` — обложка для выдачи. Нужен отдельный адрес полного
изображения и его размеры:

```json
"image_url": "https://…/night-watch-full.jpg",
"image_width": 6720,
"image_height": 5544
```

Лучше — **IIIF**, если источник его отдаёт: у Рейксмюсеума, Лувра, Метрополитена и Google Arts
IIIF есть, и это ровно тот протокол, который делает глубокий зум без скачивания 60-мегабайтного
JPEG. Тогда вместо `image_url` достаточно базового адреса:

```json
"iiif_base": "https://iiif.rijksmuseum.nl/public/SK-C-5"
```

Фронт сам соберёт из него и тайлы для зума, и кроп фрагмента (`/x,y,w,h/600,/0/default.jpg` —
кроп считает сервер IIIF, нам не нужно ни резать, ни хранить куски). Если IIIF у источника нет —
`image_url` с размерами, зум по одному файлу; тогда, пожалуйста, держите разумный предел (2–4 тыс.
пикселей по длинной стороне), иначе телефон его не откроет.

## 3. Разбор картины

Блок «Смысл и анализ»: связный текст и несколько коротких тезисов-символов.

```json
"analysis": {
	"text": "Полотно заказала стрелковая рота…",
	"points": [
		{ "title": "Тайна золотой девочки", "text": "Девочка с курицей на поясе — эмблема гильдии…" },
		{ "title": "Игра светотени", "text": "Свет падает не по физике, а по смыслу…" }
	]
}
```

- `text` — до 10 000 символов, обычный текст с абзацами (не HTML: вставлять чужую разметку в
  страницу мы не будем).
- `points` — до 10, `title` до 120, `text` до 600.
- Отличается от `trivia` тем, что это разбор, а не список любопытных фактов; `trivia` остаётся
  как есть.

Кнопка «Слушать разбор» в макете есть, **но озвучку в эту задачу не берём.** Если решите делать
позже — хватит одного поля `audio_url` рядом с `analysis`; пока его быть не должно, чтобы в
интерфейсе не появилась кнопка, за которой тишина.

## 4. Музей — сущность, а не строка

Сейчас музей — текст в `metadata.museum` плюс `city`. Из-за этого «Рейксмюсеум», «Рейксмузей» и
«Rijksmuseum» — три разных музея, у фильтра `museum` в выдаче каша, а страницы музея нет.

Нужно так же, как сделано со студиями: справочник со slug'ом, названием, городом, страной,
логотипом и сайтом, страница `/museums/{slug}` и фильтр по slug'у, а не по строке.

Плюс статус конкретной картины в музее:

```json
"display": { "status": "permanent", "room": "Галерея славы" }
```

`status`: `permanent` (в постоянной экспозиции), `storage` (в запасниках), `loan` (на выставке в
другом месте), `unknown`. В интерфейсе это бейдж «В постоянной экспозиции» — зритель хочет знать,
можно ли прийти и увидеть холст своими глазами.

Это самый дорогой пункт из четырёх (миграция строк в справочник, склейка дублей) и самый не
срочный: страница картины работает и со строкой. Если времени мало — отложите, но тогда хотя бы
не плодите новые написания при импорте.

## Чего не нужно

- Отдельной сущности для фрагмента: ни оценок, ни рецензий, ни своей страницы у «золотой девочки»
  нет и не будет. Это часть картины, а не произведение.
- Озвучки разбора — см. выше.
- «Другие работы художника» — уже работает: `GET /search?person={slug}&role=artist`. Новых ручек
  не надо, проверьте только, что сортировка по рейтингу там осмысленная.

## Импорт

Руками это не наполнить: координаты фрагментов и разбор пишет человек, но исходники, размеры,
музей и IIIF — машинные. У Рейксмюсеума и Метрополитена открытые API с IIIF и размерами,
у Wikidata — связка «картина → музей → инвентарный номер». Начните с них: без исходника высокого
разрешения вся остальная работа не видна.

## Что получит фронт

- Ленту фрагментов под «О картине» — и переход зумом к детали на самом холсте.
- Глубокий зум вместо увеличения превью, которое сейчас расплывается на втором шаге.
- Блок разбора рядом с фактами.
- Бейдж «В постоянной экспозиции» и ссылку на музей (после пункта 4).
