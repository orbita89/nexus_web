# Связанные подборки (задача бэкенду)

Блок «Похожие подборки» внизу страницы особой коллекции сейчас собирается на фронте
эвристикой (общие фильмы из `preview`, тема). Нужны **ручные связи**: админ сам указывает,
какие подборки показывать рядом с данной и в каком порядке. Автоматический подбор
(`/collections/{id}/similar` из `collection-saves-similar.md`) — отдельная задача на потом;
связи от него не зависят и имеют приоритет.

## Модель

Таблица `collection_links`:

| Колонка         | Тип                                       | Примечание          |
| --------------- | ----------------------------------------- | ------------------- |
| `collection_id` | uuid, FK → collections, ON DELETE CASCADE | откуда связь        |
| `related_id`    | uuid, FK → collections, ON DELETE CASCADE | на что ссылается    |
| `position`      | int                                       | порядок показа, с 0 |
| `created_at`    | timestamptz                               |                     |

- PK `(collection_id, related_id)`; связь с самой собой запрещена (CHECK).
- Связь **направленная**: «Дюна» → «Фантастика 80-х» не означает обратную. Обратную
  админ добавляет сам (фронт предложит галочку «Связать в обе стороны», это два запроса).
- Не больше 12 связей у одной коллекции.
- Связывать можно только **публичные** коллекции (особые или нет). Если связанная
  коллекция стала приватной или удалена — в выдаче она пропускается (удалённая уходит
  каскадом), сама связь у приватной остаётся и вернётся, если коллекцию снова откроют.

## Чтение

`GET /api/v1/social/collections/{id}/related` — гостю доступно, кэшируемо (`s-maxage=600`).

- Ответ: `Collection[]` в порядке `position`, только публичные.
- Коллекции нет или она приватная чужая — 404.
- Пустой массив, если связей нет (фронт тогда покажет эвристику / позже `/similar`).

Опционально (удобно для SSR, один запрос вместо двух): поле `related: Collection[]` в
`CollectionDetail` (`/collections/{id}` и `/collections/by-slug/{slug}`). Если сделаете
поле — отдельный GET всё равно нужен для админки.

## Изменение (только admin)

Все ответы — актуальный список, как у GET (`Collection[]`). Не админ — 403.

- `PUT /api/v1/social/admin/collections/{id}/related` — заменить весь список разом:
  тело `{ "ids": ["uuid", ...] }`, порядок в массиве = `position`. Удобно для
  перетаскивания в админке.
- `PUT /api/v1/social/admin/collections/{id}/related/{related_id}` — добавить одну связь
  в конец (идемпотентно; если уже есть — не меняется), тело `{ "position"?: number }`
  необязательно — вставить на место со сдвигом остальных.
- `DELETE /api/v1/social/admin/collections/{id}/related/{related_id}` → 204
  (идемпотентно).

## Ошибки

Формат как во всём API: `{error, code, field?}`.

| Случай                          | Ответ                                           |
| ------------------------------- | ----------------------------------------------- |
| Связь с самой собой             | 400 `validation`, `field: "ids"` / `related_id` |
| Дубликаты в `ids`               | 400 `validation`, `field: "ids"`                |
| Больше 12 связей                | 400 `validation`, `field: "ids"`                |
| Связываемая коллекция приватная | 400 `collection_private`                        |
| Коллекции (любой из двух) нет   | 404                                             |
| Не админ                        | 403                                             |

## Готово, когда

- Миграция с таблицей и ограничениями, эндпоинты описаны в `documents/api/social.json`.
- Тесты: добавление, порядок, замена списком, удаление, каскад при удалении коллекции,
  пропуск приватных в выдаче, лимит 12, 400/403/404.

## Фронт после реализации

- `pnpm api:types`, функции `getRelatedCollections`, `adminSetRelated`,
  `adminAddRelated`, `adminRemoveRelated` в `src/lib/social/collections.ts`.
- `src/routes/collections/[id]/+page.ts`: «Похожие подборки» = связи; если их нет —
  текущая эвристика `rankSimilar` (`src/lib/social/featured.ts`).
- Админ на странице коллекции и в «Подборках»: блок «Связанные подборки» — поиск
  коллекции, добавить, убрать, перетащить порядок, галочка «Связать в обе стороны».
