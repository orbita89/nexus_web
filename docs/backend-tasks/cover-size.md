# Размеры обложки в выдаче (задача бэкенду)

Стена картин (`/paintings`, `ArtWall.svelte`) показывает холсты в их собственных пропорциях.
Пропорции узнаются только после загрузки файла, поэтому до неё карточка держит место
заглушкой 4:5 — и когда картина оказывается широкой, высота карточки один раз меняется.

Нужны размеры исходника в `EntitySummary` (и в `EntityDetail`, раз они всё равно известны):

```json
"cover_url": "https://…/mona-lisa.jpg",
"cover_width": 1600,
"cover_height": 2389
```

- Пиксели исходного файла, целые; обложки нет — полей нет (или `null`).
- Нужны у всех видов работ, но в первую очередь у картин: у постеров пропорции и так 2:3.
- Фронт тогда поставит каждой карточке точное `aspect-ratio` до загрузки: стена сложится
  сразу и больше не дёрнется (Cumulative Layout Shift → 0).

Если размеры не хранятся, их можно взять один раз при импорте обложки и положить рядом с
`cover_url`; пересчитывать на каждый запрос не нужно.
