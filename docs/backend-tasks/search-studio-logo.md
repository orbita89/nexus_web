# Логотип студии в подсказках поиска

В фильтрах раздела студию теперь выбирают из сетки карточек: открыл «Студия» — видишь девять
студий с числом работ. У людей в такой же сетке есть лица (`photo_url` приходит из
`GET /api/v1/catalog/search/people`), у стран — флаги, а у студий картинки нет: карточка —
только название и счётчик, и ряд выглядит голым там, где рядом сетка лиц.

Логотип у студии при этом есть: `GET /api/v1/catalog/studios/{slug}` отдаёт `logo_url`, и в
карточке фильма мы его показываем (`StudioRef.logo_url`). Нет его только в выдаче поиска:

```
GET /api/v1/catalog/search/studios?q=warner&kind=movie&limit=9
→ [{ name, slug, count }]        // StudioHit
```

Тянуть логотипы девятью запросами `/studios/{slug}` на каждое открытие панели мы не будем:
выдачу фильтров отдаёт Meilisearch одним запросом, и так и должно остаться.

## Что нужно

Добавить `logo_url` в `StudioHit`:

```
GET /api/v1/catalog/search/studios?q=warner&limit=9
→ [{ name: "Warner Bros. Pictures", slug: "warner-bros-pictures", count: 184,
     logo_url: "https://…/warner.png" }]
```

- Поле необязательное: `null` или отсутствует — фронтенд просто не рисует картинку
  (`StudioLogo` так и устроен), ломаться ничего не должно.
- Важно, чтобы логотип лежал **в документе индекса Meilisearch** и приезжал тем же ответом, а не
  дочитывался из PostgreSQL по каждому хиту: панель фильтров — это один запрос в поиск, и
  добавление картинок не должно превращать его в девять.
- Тот же адрес, что в `/studios/{slug}` и `StudioRef`, без отдельного размера — картинки
  мелкие (20×32 CSS-пикселя), подойдёт имеющийся PNG.
- У студии без страницы (`slug: null`) логотипа, скорее всего, и нет — это нормально.

То же поле пригодится в `/search/publishers` и `/search/museums`: карточки там те же, и издателя
с музеем выбирают так же глазами.

## Что фронтенд включит после

| Бэкенд                          | Фронтенд                                    |
| ------------------------------- | ------------------------------------------- |
| `logo_url` у `StudioHit`        | логотип в карточке студии в панели фильтров |
| `logo_url` у издателей и музеев | то же в их панелях                          |

После слияния: `pnpm api:types`, затем `pnpm verify`.
