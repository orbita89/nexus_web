# Вопросы и предложения к бэкенду

Код бэкенда из фронтенда не меняем — собираем сюда, решаем в `nexus_project`. Промт для сессии
бэкенда со всеми открытыми пунктами — [backend-prompt.md](backend-prompt.md).

## Dev-окружение

1. **Ссылки из писем и OAuth в dev ведут на бэкенд.** `APP_BASE_URL=http://localhost`, а nginx
   отдаёт `/` приложению. Сейчас обход — `APP_BASE_URL=http://localhost:5173` в `infra/.env`
   (описано в README фронтенда). Когда фронтенд поедет в docker: nginx `/` → фронтенд,
   `/api`, `/ws`, `/docs` → приложение.

## Чего не хватает в API

2. **Свой голос за рецензии вне карточки.** `GET /entities/{slug}/votes/mine` — по одной
   сущности, а в профиле (`/u/{username}/reviews`) и в ленте рецензии разных произведений: там
   кнопки 👍/👎 работают, но свой прошлый голос не подсвечен. Предложение:
   `GET /social/reviews/votes/mine?ids=a,b,c` (до 100) → `{"<id>": 1 | -1}`.

## Надёжность

3. **Замок переиндексации переживает рестарт.** Если процесс убит посреди перестройки (в dev —
   cargo-watch на любом изменении файлов), ключ `nexus:v1:catalog:reindex-running` остаётся в
   Redis с TTL ~2 ч, и до его истечения `POST …/search/reindex/stream` отвечает 409 «уже идёт».
   Предложение: короткий TTL с продлением, пока перестройка жива, или снимать замок при старте.
   Фронтенд на 409 пишет «Перестройка уже идёт».

## Статические карточки

4. **Страницы людей — тоже статика?** Бэкенд шлёт в ISR и `/people/{slug}`; фронтенд их пока
   пропускает (`skipped`): люди рендерятся SSR. Сделать статикой — тот же приём, что у карточек.

## Холодный архив: чего нет в API

Фронтенд подключил `GET /archive/search` и `POST /admin/archive/promote/{slug}` (раздел «Архив»
в админке, блок «В архиве» в поиске). Пока не нужно, но понадобится, если интерфейс пойдёт дальше:

5. **Отправить фильм с сайта в архив вручную** — обратная операция к промоушену, кнопка в форме
   сущности. Сейчас фильм можно только скрыть (`active: false`), в архив он не попадает.
6. **Пересборка горячего слоя и архива из админки** — сейчас только CLI
   `nexus archive dump|build`. Нужен эндпоинт-поток (`JobEvent`, как у переиндексации) с ходом
   пересборки; во время сборки промоушен отвечает 409, и админка могла бы показать, когда она
   закончится.
7. **Сведения об архиве и поиск шире топа**: число документов (`GET /archive/stats` или `total`
   в ответе), фильтры по году и типу, пагинация — сейчас только топ-20, при 20 результатах
   админка просит уточнить запрос.
8. **Данные TMDB для строк архива** — постер и краткое описание, чтобы админ видел, что
   возвращает, не открывая themoviedb.org.

## Решено

Карточка v2 и старые долги — бэкенд `a0a7d06..83e2cfb`, фронтенд подключил:

- Машинные коды ошибок `{"error", "code"}` — сообщения по `code` (`errors.ts`), текст — запасной путь.
- `GET /auth/admin/users/page?q=` — `Page<UserView>` с `total`, поиск по username и email;
  обход типов убран.
- `?sort=new|popular|rating|title` в `GET /entities` — переключатель в разделах каталога.
- `GET /social/ratings?slugs=` — оценки на постерах, один запрос на страницу сетки.
- `release_date` в `EntityRef` — «Дюна (2021)» в плашках тем, рецензий профиля, коллекций, ленты.
- `?contains={slug}` у коллекций — «В коллекцию» одним запросом; `Collection.preview` — коллаж.
- `GET /catalog/tags/{slug}` — страница тега; `Tag.kind` — жанры отдельно от тегов.
- Спойлеры (`is_spoiler`), 409 `not_released` до премьеры.
- Голоса (`PUT/DELETE …/vote`, `votes/mine`), комментарии к рецензиям (реалтайм
  `review.commented` / `review.comment_deleted`), реакции, отметки «позже» / «просмотрено» —
  через API, `localStorage` убран.
- `EntityDetail.related` и связи в админке; `GET …/similar` — «Рекомендации».
- `metadata.studios`, `awards`, `trivia` — «Производство и факты» и форма админки.

- Окно повтора для refresh: 30 секунд, повтор заменённого токена возвращает ту же пару
  (бэкенд, `27830bd`).

- Сигнал фронтенду об изменениях (ISR): `publish.rs` шлёт `{"paths"}` после каждой правки,
  перестройка — `{"all": true}`; ход — потоком `JobEvent` в админку.

- Схемы `ReviewSort`, `ThreadSort` и уникальные `operationId` в контрактах. `pnpm api:types` теперь
  падает с понятным сообщением, если контракт снова сломается, а не обходит ошибку.
- `has_password` в `UserView`: пароль при смене email и «Задать пароль» вместо смены — по нему.
- `Retry-After` и `retry_after` у 429: фронтенд пишет «Попробуйте через 80 с».
- Трейлеры: вместо предложенного `trailer_url` (видеофайл) — `metadata.trailers`, источники по
  приоритету (YouTube, Rutube), плеер в модалке по кнопке. Сейчас в ветке
  `feature/catalog-trailers` (поверх `fix/contract-and-auth-fields`), в `main` бэкенда ещё нет.
