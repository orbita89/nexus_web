# WebSocket (реалтайм): только у чата

Прод — слабый сервер (2 ГБ RAM, 2 ядра). Каждое открытое WebSocket-соединение держит память на
сервере (буферы, очередь, задачи — ~8–10 КБ, замер 2026-11-28) и место в nginx. Если открывать сокет каждому
вошедшему на каждой странице, ресурсы кончатся на нескольких тысячах человек — даже когда в чат
никто не пишет. Поэтому с 2026-11-27 правило такое:

**Нет открытого чата — нет сокета. Один человек — один сокет.**

## Как работает

| Правило                                                                                                                                                                                         | Где                                                                      |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Сокет открывается только при открытой панели чата у вошедшего; закрыли панель — закрывается через 4 с (`IDLE_CLOSE_MS`)                                                                         | `src/lib/components/chat/ChatPanel.svelte`, `src/lib/realtime/client.ts` |
| Вход сокет не открывает: `syncRealtimeAuth` лишь передаёт токен в уже открытый                                                                                                                  | `src/lib/realtime/realtime.svelte.ts`                                    |
| Гостю сокет не открывается: чат у гостя только для чтения, по REST                                                                                                                              | `ChatPanel.svelte`                                                       |
| Один сокет на браузер: «главная» вкладка держит Web Lock `nexus-ws` и сокет, остальные получают события и шлют сообщения через `BroadcastChannel`; главную закрыли — lock переходит к следующей | `src/lib/realtime/tabs.ts`                                               |
| Один сокет на человека (и между устройствами): сервер закрывает прежнее соединение кодом 4000 `replaced`; клиент не переподключается, в панели — «Чат открыт в другом окне… Подключиться здесь» | бэкенд `modules/realtime/src/registry.rs`, `client.ts`                   |
| Вкладка в фоне дольше 1 мин снимает свои подписки (скрыты все — сокет закрывается); вернулась — подписки обратно и перечитать                                                                   | `tabs.ts` (`HIDDEN_SUSPEND_MS`)                                          |
| Переподключение: 1, 2, 4 … 30 с ±50 % (разброс — чтобы после рестарта сервера клиенты не шли волной), не больше 5 попыток подряд (`MAX_ATTEMPTS`), дальше «Нет связи с чатом. Повторить»        | `client.ts`                                                              |

## Что временно отключено и почему

Всё ниже работало через тот же сокет. С правилом «сокет только у чата» каждое из этих мест само
открывало бы сокет на своей странице — а это и есть тысячи лишних соединений.

| Что                                              | Было                                                                                   | Сейчас                                                                                                                | Как включить обратно                                                                                                                      |
| ------------------------------------------------ | -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Уведомления об ответах (тосты на всех страницах) | канал `user:me`, событие `reply.created`                                               | убрано из `src/routes/+layout.svelte` (комментарий на месте `<ReplyToasts />`)                                        | вместе с форумом (ссылки ведут на тему форума, она в разработке); для опроса REST нужен эндпоинт списка ответов на бэкенде — его пока нет |
| Лента `/feed`                                    | события интересов                                                                      | заглушка «Идёт разработка» (`Stub`)                                                                                   | вернуть страницу из git (`src/routes/(protected)/feed/+page.svelte`)                                                                      |
| Тема форума `/forum/{id}`                        | канал `thread:<id>`                                                                    | заглушка «Идёт разработка», загрузчик ничего не грузит                                                                | вернуть `+page.svelte` и `+page.ts` из git                                                                                                |
| Карточка (фильм/книга/игра)                      | канал `entity:<slug>`: чужие рецензии, обсуждения, реакции появлялись без перезагрузки | `useRealtime(() => [], …)` в `src/lib/components/card/EntityPage.svelte`                                              | уже без сокета: перечитывается при возврате на вкладку после >1 мин в фоне; сокет — вернуть `[`entity:${entity.slug}`]` для вошедшего     |
| Колокольчик «Следить»                            | канал `user:me`: нажали на телефоне — переключился на компьютере                       | `useRealtime(() => [], …)` в `src/lib/social/watch.svelte.ts`; сама кнопка работает, состояние — по REST при открытии | вернуть `['user:me']` для вошедшего                                                                                                       |

Найти все места: `grep -rn "ВРЕМЕННО ОТКЛЮЧЕНО" src`.

## Если включать обратно

Не через постоянный сокет. Варианты без него:

- **Перечитать при фокусе** (`visibilitychange` → visible) — карточка, колокольчик: бесплатно,
  данные свежие, когда человек на них смотрит.
- **Опрос REST раз в 30–60 с только у видимой вкладки** — уведомления об ответах, лента, форум.
  Один лёгкий GET в минуту дешевле открытого сокета и переживает рестарты сервера.
- Подписка через сокет — только пока чат и так открыт (тогда канал добавляется в уже открытое
  соединение и ничего не стоит).
